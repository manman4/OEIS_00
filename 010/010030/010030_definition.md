# A010030 の定義と具体例

[OEIS A010030](https://oeis.org/A010030) は、順列の中に現れる「連続する整数のペア」の run 数を数える不規則三角形である。

## 1. 定義

`1, 2, ..., n` の順列を

$$
p=(p_1,p_2,\ldots,p_n)
$$

とする。

### Consecutive pair

隣接する 2 項 $p_i,p_{i+1}$ が

$$
|p_{i+1}-p_i|=1
$$

を満たすとき、その 2 項を **consecutive pair** と呼ぶ。

- `4,5` のような上向きのペア
- `5,4` のような下向きのペア

の両方を数える。方向は区別しない。

各 consecutive pair は、小さい方を $a$ として、整数直線上の辺

$$
\{a,a+1\}
$$

で表せる。

### Run

辺

$$
\{a,a+1\},\{a+1,a+2\},\ldots,\{b,b+1\}
$$

が連続しているとき、それらを 1 つの **run** とする。したがって、run 数は、順列に現れた consecutive pair を整数直線 `1--2--...--n` 上に置いたときの連結成分数である。

例えば `12, 23, 34` がすべて現れても、これは 3 run ではなく 1 run である。一方、`12` と `34` だけが現れる場合は、間の `23` がないので 2 run となる。

順列 $p$ の run 数を $r(p)$ と書く。

異なる run は互いに頂点を共有せず、各 run は少なくとも 2 個の整数を使う。このため run 数の最大値は $\lfloor n/2\rfloor$ である。

### 三角形 T(n,k)

run 数が $r$ である $S_n$ の順列数を $N(n,r)$ と書く。n が 2 以上の場合、

$$
T(n,k)=\frac{1}{2}
N(n,\lfloor n/2\rfloor-k),
\qquad
0\leq k\leq\lfloor n/2\rfloor.
$$

つまり、行の左から右へ進むにつれて、対象となる run 数は

$$
\lfloor n/2\rfloor,
\lfloor n/2\rfloor-1,
\ldots,0
$$

と減っていく。

初期行 $n=1$ は例外として

$$
T(1,0)=1
$$

とする。

## 2. なぜ 2 で割れるのか

順列 `p` と、それを逆から読んだ順列 `reverse(p)` を考える。

```text
p          = (p1, p2, ..., pn)
reverse(p) = (pn, ..., p2, p1)
```

`p` と `reverse(p)` に現れる consecutive pair の集合は同じであり、上向きと下向きが入れ替わるだけなので run 数も同じである。

n が 2 以上の順列は相異なる要素からなるため、`p = reverse(p)` にはならない。したがって、同じ run 数を持つ順列は反転によって 2 個ずつの組になり、その個数は必ず偶数になる。A010030 は各組を 1 個として数えるため、最後に 2 で割っている。

## 3. 具体例

### 例1: 上向きと下向き

順列 `1 3 2` では、隣接項は `13`, `32` である。

- `13`: 差の絶対値が 2 なので数えない。
- `32`: 差の絶対値が 1 なので consecutive pair `23` として数える。

したがって consecutive pair は `23` だけで、run 数は 1 である。`32` は下向きだが、上向きの `23` と同じ種類のペアとして扱う。

### 例2: 複数のペアが 1 run を作る場合

順列

```text
1 4 5 6 2 3
```

の隣接項を調べる。

| 隣接項 | 差の絶対値 | consecutive pair |
|---|---:|---|
| `14` | 3 | なし |
| `45` | 1 | `45` |
| `56` | 1 | `56` |
| `62` | 4 | なし |
| `23` | 1 | `23` |

`45` と `56` は連続する辺なので同じ run に属する。`23` はそこから離れているので別の run になる。

```text
run 1: 23
run 2: 45--56
```

よって run 数は 2 である。$n=6$ では $\lfloor n/2\rfloor=3$ なので、

$$
k=3-2=1
$$

となり、この順列は $T(6,1)$ の計数対象である。

### 例3: n=4 の全順列による行の計算

$n=4$ では $\lfloor n/2\rfloor=2$ であり、24 個の順列は run 数によって次のように分かれる。

| run 数 $r$ | 順列数 | 対応する $k=2-r$ | 2 で割った値 |
|---:|---:|---:|---:|
| 2 | 6 | 0 | 3 |
| 1 | 16 | 1 | 8 |
| 0 | 2 | 2 | 1 |

各分類を具体的に書くと次のとおりである。

- 0 run: `2413`, `3142`
- 1 run: `1234`, `1324`, `1342`, `1423`, `1432`, `2314`, `2341`, `2431`, `3124`, `3214`, `3241`, `4123`, `4132`, `4213`, `4231`, `4321`
- 2 run: `1243`, `2134`, `2143`, `3412`, `3421`, `4312`

代表例を見ると、

- `1234` には `12`, `23`, `34` があるが、すべてつながっているので 1 run。
- `2143` には `21` と `43`、すなわち辺 `12` と `34` があり、離れているので 2 run。
- `2413` には consecutive pair がないので 0 run。

したがって $n=4$ の行は

$$
[T(4,0),T(4,1),T(4,2)]=[3,8,1]
$$

となる。

## 4. 三角形の初めの部分

行内では $k=0,1,\ldots,\lfloor n/2\rfloor$ の順に並べる。

```text
n=1: 1
n=2: 1, 0
n=3: 3, 0
n=4: 3, 8, 1
n=5: 25, 28, 7
n=6: 17, 155, 143, 45
n=7: 259, 1005, 933, 323
n=8: 131, 2770, 7488, 7150, 2621
```

これを行ごとに平坦化すると、

```text
1, 1, 0, 3, 0, 3, 8, 1, 25, 28, 7, 17, 155, 143, 45,
259, 1005, 933, 323, 131, 2770, 7488, 7150, 2621, ...
```

となる。
